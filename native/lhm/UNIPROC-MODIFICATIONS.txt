Uniproc builds LibreHardwareMonitor commit
2808d80564b6761e1b01f42fabfd966ed695fcbc and DiskInfoToolkit commit
073a31312b9f5147340488e551e06df5f3ab9715 with the distributed patches.

skip-unused-nvml.patch adds an opt-out switch to NvidiaML.Initialize.
Uniproc enables it because this bridge exports temperatures and CPU package
watts. NVIDIA temperatures retain NVAPI; NVML-only GPU power, memory and
PCIe metrics are not exported.

diskinfo-project.patch selects the pinned DiskInfoToolkit project when its
source root is provided. stream-pci-ids.patch replaces the resident whole
PCI catalog with a streaming lookup of the requested vendor/device. It
retains the same embedded catalog, parser, names and missing-ID behavior.
It does not omit controller identity or temperature readings.
