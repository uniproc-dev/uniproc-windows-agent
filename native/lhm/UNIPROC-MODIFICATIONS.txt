Uniproc builds LibreHardwareMonitor commit
2808d80564b6761e1b01f42fabfd966ed695fcbc with skip-unused-nvml.patch.

The patch adds an opt-out switch to NvidiaML.Initialize. Uniproc enables it
because this bridge exports temperatures and CPU package watts. NVIDIA
temperatures retain the existing NVAPI implementation. NVML-only GPU power,
memory and PCIe metrics are not exported by this bridge.
